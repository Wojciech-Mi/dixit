Uruchomienie na własnym PC / Hostingu

💡 Dobra wiadomość: Ta aplikacja posiada już wbudowany moduł WebRTC P2P (PeerJS)! Oznacza to, że telefony łączą się ze sobą bezpośrednio po zeskanowaniu kodu QR nawet bez instalowania Node.js.

Jeśli jednak chcesz uruchomić klasyczny serwer Node.js + Express + Socket.io lokalnie na swoim komputerze lub wrzucić go na darmowy hosting (np. Render.com), kliknij poniższy przycisk, aby pobrać gotowy plik server.js:

# Instrukcja uruchomienia w 30 sekund na PC:
1. Umieść pobrany server.js oraz index.html w jednym folderze.
2. W terminalu wpisz: npm init -y && npm install express socket.io
3. Uruchom serwer: node server.js
4. (Opcjonalnie HTTPS dla kamery i gry poza Wi-Fi): npx cloudflared tunnel --url http://localhost:3000
